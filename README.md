# 🧬 DNA Detective - Bioinformatics Investigation Game

## 📌 Project Overview

DNA Detective is a beginner-friendly Python-based bioinformatics game that combines programming concepts with basic DNA sequence analysis.

In this game, the player takes the role of a Bioinformatics Detective and investigates DNA sequences by analyzing nucleotides, calculating GC content, searching for DNA patterns, and detecting mutations.

The project is designed as an interactive way to learn basic computational biology concepts using Python.

---

## 🎯 Objectives

The main objectives of this project are:

- To apply Python programming concepts to a bioinformatics-based problem.
- To perform basic DNA sequence analysis.
- To identify differences between DNA sequences.
- To search for specific patterns within DNA sequences.
- To calculate nucleotide composition and GC content.
- To develop an interactive console-based game.

---

## 🧬 Features

### 1. DNA Analysis
The player can enter a DNA sequence and obtain:

- DNA sequence length
- Number of Adenine (A)
- Number of Thymine (T)
- Number of Guanine (G)
- Number of Cytosine (C)

### 2. GC Content Calculation
The game calculates the percentage of G and C nucleotides in a DNA sequence.

### 3. DNA Pattern Search
The player can search for a particular nucleotide pattern within a DNA sequence.

### 4. Mutation Detection
The game compares a sample DNA sequence with a reference sequence and identifies differences between them.

### 5. Sample Investigation
The player can investigate different fictional DNA samples and compare them with the reference DNA.

### 6. Random DNA Challenge
A random DNA pattern is selected and the player must identify its position in the sequence.

### 7. Score System
Players earn points for successfully completing different analysis and investigation tasks.
